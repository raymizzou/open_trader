# BUY 计划与独立精确 ID 撤单

2026-10-13，#339：自动 LP 每轮根据当前账户挂单、持仓成本、资金和候选形成目标。计划仅包含新增 BUY 的固定价格、数量和请求身份。收益选优的撤单由独立路径登记和发送；它不取得订单保护控制权，也不成为 BUY 动作。

本决定取代 [ADR 0003](0003-lp-plan-time-account-validation.md) 中计划包含撤单、等待撤单结果完成轮次、部分成交或已有保护状态阻止收益选优的规定。规划时账户校验、BUY 固定价量、财务算法、身份检查和防重规则继续适用。

BUY 本地尝试完成或计划为空后，开始原配置轮次间隔。撤单 ACK、拒绝或 UNKNOWN 均保留各自审计；不据此提前释放实际 BUY 名额或资金。下一轮重新读取当前事实，不恢复旧计划的发送权限，也不由旧撤单 UNKNOWN 保留或排除当前订单。不同轮次、保护和收益选优可以各自发送新的精确 ID 请求；同一逻辑请求不得重放。

新增 BUY 的余额或 allowance 不足，不单独成为撤掉已知现有报价的理由；现有报价仍受配置预算、名额和收益排名约束。

部分成交 BUY 的剩余挂单参与排名和撤单。已成交库存与成本保留，不为补足名额自动 SELL。保护撤掉的候选仍可重新入选；新 BUY 使用新请求、新订单 ID 和当前盘口的保护基线。旧 ID 的迟到撤单可能造成短暂空位；下一轮按真实状态补位，旧请求不得作用于新 ID。

正常核对证明原保护锚点精确 ID 已终态且零成交时，同会话、同 token、同价格的已知未成交 LIVE 受保护订单可接替锚点。只修改锚点 ID，保留全部当前桶字段与基线来源。当前 LIVE 优先于历史；未知、部分成交、身份不明、真实撤单／保护控制、停止或止损不被重置。仅从完整挂单列表消失不构成终态证明。

## 预计收益未知保护

收益指当前预计做市奖励收益率，不是历史盈亏、已付奖励或费用报表。当前 LP 账户所有已纳管 BUY，包括手动来源，按账户和精确订单 ID 保存首次未知时间。连续失败不移动起点；有效已知收益（包括零）清除计时；重启保留起点，新订单 ID 不继承旧计时。

预计收益连续未知 600 秒后，首个正常 LP 监控检查登记精确 ID 风险撤单，即使没有替代候选。每个请求保留独立审计和发送身份，不重放原请求；后续新的有效挂单事实仍可形成新的精确 ID 请求。暂停自动池只撤销未发送 BUY 的权限；正常保护及此规则继续运行，不依赖页面或新 BUY 轮次。SELL 不使用此计时，原持仓、数量、身份及不超卖规则保留。

## 资源与权限

买计划完成不表示撤单 HTTP 已结束。既有 LP 关闭检查收集排队、实际发送及回执应用中的撤单发送器；发送器仍使用 Store 或客户端时，runtime 保持 STOPPING 和 owner。真实发送结束后才能关闭这些资源。

独立撤单仍遵守当前 runtime、owner、全局运行许可及账户身份。自动 BUY 的暂停或交易配置版本不成为独立撤单的业务否决。登记失败不发送任何该批请求，已登记但确定未发送的原请求以独立拒绝审计保留；进程中断后的 pending 历史不伪造为拒绝，也不恢复发送。

实现复用既有会话 payload、精确 ID 撤单审计和 LP 监控，不增加数据库表、SDK 适配器或常驻服务。聚焦验证、独立评审、CI、合并和部署分别确认；本决定不授权生产操作。

## 2026-10-23：新事实驱动的完整撤单流程

LP-CANCEL-20261023 / LPCANCEL-FLOW-P2，#410。保护触发后，精确订单的撤单意图持续到目标不再挂单；
健康读取不撤销意图。每份通过原接纳的新原始挂单来源，对同一精确 BUY 最多发送一次。
仅重新包装 observation、重复消费来源或页面 GET 不增加资格；两池和多个保护原因共享逐 ID 去重。
仍为 LIVE 时，新事实可生成独立 request，即使旧 CANCEL 尚未返回。旧请求不重放，各次审计、回执及实际句柄分别保留。
普通收益轮换仍须重新满足当前条件，不恢复旧决定的发送权限。

CANCEL 不占用 BUY/SELL 下单的应用层两个槽位。撤单沿用现有 SDK 传输、连接池、网络超时和 provider 限制；
不新增主动 kill、五秒终止、独立重试计时器或发送前 GET。每个真实 HTTP 只计一个 owner，组内逐 ID 别名不重复计数。
close 仍须等待每个实际线程退出；纯 pending CANCEL 等待正常读取期限或完成通知，不使 Scheduler 空跑。

明确 canceled 为 accepted，明确 not_canceled 为 rejected，并只记录安全原因码；遗漏、矛盾或异常为 UNKNOWN。
ACK 不证明最终成交量。合法终态后，20 原量、3 实际成交对应 17 未成交撤销，终态审计占款为 0。
当前事实以精确父请求身份更新 progress，原 UNKNOWN 回执保留，迟到旧 progress 不回退新事实。
仅从完整挂单列表消失，不宣称 canceled，也不补造零成交。

下一份完整有效账户事实直接决定当前挂单、资金和库存。历史 UNKNOWN 或仅 pending CANCEL 不形成新 BUY 预留；
真实未决 BUY、余额或 allowance 不足、来源不完整/过期/错误身份仍阻止下单。实际挂单占款不提前释放，
不用预计撤单回款，不自动 SELL 已成交库存。重启恢复已持久保护事实，但旧 request 不恢复发送权。
