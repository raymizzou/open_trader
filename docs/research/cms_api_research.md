# 招商证券行情与持仓 API 调研

> 调研日期：2026-07-16  
> 范围：招商证券股份有限公司（中国内地）为主，文末单列招商证券国际（香港）。“API”指客户可用程序调用的接口，不把人工导出、网页或 App 界面算作 API。

## 结论

**有可行接口，但没有发现面向所有零售客户、在线注册 API Key 即可使用的招商证券公开 OpenAPI。**

目前最现实的路线是向招商证券申请其官方 QMT / MiniQMT 权限，再通过迅投的 `XTQuant` Python API 获取行情和账户持仓。招商证券官方页面显示，QMT V2.0.14.1 于 2026-03-27 更新，面向机构投资者及高净值个人，实盘需联系营业部客户经理开通：

- 行情：`xtdata` 可取历史和实时 K 线、分笔、财务数据、合约信息等；实际能取得的数据与登录的 MiniQMT 行情权限一致。
- 持仓：`xttrader.query_stock_positions()` / `query_stock_position()` 可查询最新持仓，也可订阅持仓变动；返回证券代码、总量、可用量、成本价、市值、冻结量、在途量等。
- 接入形态：不是公网 REST API。程序与本机或机构内网中的 MiniQMT 客户端通信，使用前要先启动并登录客户端。
- 开通条件：迅投公开资料确认招商证券属于其合作券商，但招商证券与迅投均未公开一个截至本调研日仍统一有效的资金门槛、佣金门槛或个人客户申请页面。因此网上常见的“50 万”“100 万”等说法不能当作招商证券官方条件，必须由客户经理或 95565 按账户、营业部、交易品种和程序化交易用途确认。

对私募、资管和专业机构，招商证券还提供 Geetek、X 极速交易产品、FPGA 行情、算法执行等机构交易能力；这类接口属于签约、专线/托管、权限审核后的机构方案，并非公开下载 SDK 即可接入。

## 方案对比

| 方案 | 行情 | 招商账户持仓 | 客户范围与门槛 | 接入方式 | 判断 |
|---|---|---|---|---|---|
| 招商证券零售官网/PC/App | 可在终端查看 | 可在登录后查看 | 普通开户客户；行情等级可能另行开通 | GUI、网页、App | **没有发现公开 API** |
| 招商证券版迅投 QMT / MiniQMT + XTQuant | 历史/实时 K 线、分笔、L1/L2（取决于权限）及基础/财务数据 | 支持查询、订阅持仓和查询资产/委托/成交 | 官方定位为机构及高净值个人；实盘联系营业部客户经理；具体资产、交易量和费用未公开 | Windows 本地客户端 + Python 库，连接 MiniQMT | **个人/专业客户最可行** |
| Geetek / X 极速交易 / 算法执行云等 | 极速行情、可含 FPGA 加速行情 | 机构交易与投资管理体系能够覆盖账户/组合，但未发现公开字段级 SDK 文档 | 私募、资管、机构与专业投资者；商务签约、技术和合规审核 | 交易终端、极速柜台、专线/托管、定制接口 | **机构方案，不是公开 API** |
| 独立第三方行情 API | 可获取市场行情 | **不能**读取招商证券账户持仓 | 按数据厂商许可和套餐 | REST/SDK 等 | 只能补行情，不能解决持仓 |
| 抓包、逆向或 UI 自动化 | 可能看到界面数据 | 技术上可能抓取 | 无官方授权；稳定性、账号安全、合规风险高 | 非官方 | **不建议** |

## 1. 官方公开 API：未发现

招商证券当前公开产品页列出 PC、手机、网页、期权客户端、电话委托、微信证券系统，以及“机构投资者软件下载”入口；页面提供的公开工具只有 Web 交易安全控件和 MD5 工具，没有开发者中心、API 文档、SDK、API Key 或 OAuth 授权入口。[招商证券官方产品下载页](https://yht.cmschina.com/download.html)

招商证券 PC 官方介绍强调行情展示、选股、交易和云同步，仍是面向人的终端功能，没有声明对零售客户开放程序接口。[招商证券 PC 官方页](https://yht.cmschina.com/)、[产品功能页](https://yht.cmschina.com/product.html)

因此，本调研只能得出“**未发现官方公开 OpenAPI**”，不能把它扩大成“招商证券内部绝对没有任何 API”。机构产品和券商授权的第三方终端显然存在接口，只是不属于公开、无门槛、自助开通的 API。

## 2. QMT / XTQuant：可同时解决行情和持仓

### 招商证券是否支持 QMT

**招商证券官方已直接确认支持。**其机构交易平台下载目录目前仍列有“招商证券 QMT 极速策略交易系统”；QMT 详情页标注版本 V2.0.14.1、更新时间 2026-03-27，称其面向有量化交易需求的机构投资者及高净值个人，集行情、交易和策略于一体，覆盖股票、债券、基金、期货、期权，并对接极速现货、两融和期权柜台。页面明确要求实盘客户联系营业部客户经理办理开通。[招商证券机构交易平台下载目录](https://update-pb.cmschina.com/update-page/index.html)、[招商证券 QMT 官方详情页](https://update-pb.cmschina.com/update-page/details/aboutQmt.html)

迅投产品页将 QMT 定位为本地部署的量化交易终端，其当前合作机构列表也包含招商证券。[迅投官网（合作机构列表）](https://www.thinktrader.net/)、[QMT 产品页](https://www.thinktrader.net/products/qmt)

这些证据能确认产品当前存在，但不能确认任一招商证券零售账户默认拥有 QMT 权限。最终应让招商证券明确：

1. 当前营业部是否提供招商证券版 QMT 或 MiniQMT；
2. 是否只开行情/回测，还是同时开实盘交易与账户查询；
3. 普通、信用、期权等账户分别支持哪些能力；
4. L1、L2、逐笔和历史数据的权限与费用；
5. 资产、交易量、佣金、策略报备和运行环境要求。

招商证券官方产品页给出的咨询渠道为 **95565 / 0755-95565** 与 `sbox@cmschina.com.cn`。[招商证券官方产品下载页](https://yht.cmschina.com/download.html)

### API 能取什么

迅投官方文档明确，XTQuant 是由 MiniQMT 衍生的 Python 框架：

- `xtdata`：历史和实时 K 线、分笔、财务数据、合约信息、板块/行业等；[XTQuant 快速开始](https://dict.thinktrader.net/nativeApi/start_now.html)、[xtdata 官方文档](https://dict.thinktrader.net/nativeApi/xtdata.html)
- `xttrader`：报单、撤单、查询资产、委托、成交、持仓，并接收资金、委托、成交和持仓变动推送；[xttrader 官方文档](https://dict.thinktrader.net/nativeApi/xttrader.html)
- 持仓查询：`query_stock_positions(account)` 返回最新持仓列表，`query_stock_position(account, stock_code)` 查询单只证券；持仓对象含账号、证券代码、持仓数量、可用数量、开仓/成本价、市值、冻结量、在途量和昨持等字段。[持仓接口与 `XtPosition` 字段](https://dict.thinktrader.net/nativeApi/xttrader.html)
- 普通柜台：官方文档还列有 `query_com_fund()` 与 `query_com_position()`，用于划拨业务查询普通柜台资金和持仓；能否在招商证券环境使用仍取决于券商部署和账户授权。[xttrader 其他查询接口](https://dict.thinktrader.net/nativeApi/xttrader.html)

上述接口返回的是账户**当前/最新持仓**，不是历史持仓时间序列；如项目需要持仓历史，应自行按日或按事件保存快照。

### 行情权限与运行限制

`xtdata` 本质上连接 MiniQMT，由 MiniQMT 处理行情请求；可用行情服务器和数据权限与 MiniQMT 一致。官方文档说明 L1 可下载历史并订阅实时数据，L2 接口主要提供实时数据且跨交易日清理。因此不能仅因 SDK 中存在 L2 函数，就假定招商账户免费拥有 L2。[xtdata 运行逻辑与数据分类](https://dict.thinktrader.net/nativeApi/xtdata.html)

迅投的通用权限表显示，“券商版”支持 Python 交易，但其基础行情档可能限制为股票、100 个标的、最高一档；更长历史、更多品种、更多档位及特色数据需要额外权限。这个表是迅投的通用产品说明，不等于招商证券对每个账户的最终授权，仍须由客户经理确认。[迅投 QMT 行情权限说明](https://dict.thinktrader.net/dictionary/?id=e2M5nZ)

官方快速开始页还要求先启动 MiniQMT；这意味着部署时通常需要一台可持续登录券商终端的 Windows 主机或机构内网环境，而不是在任意 Linux 云服务器上直接调用招商证券公网 API。[XTQuant 快速开始](https://dict.thinktrader.net/nativeApi/start_now.html)

## 3. 招商证券机构交易与柜台接口

招商证券在上交所《交易技术前沿》发表的机构平台实践材料称，其机构产品体系包括：

- 支持极速交易及 FPGA 硬件加速行情的 **X 极速交易产品系列**；
- 面向机构和专业投资者的“交易大师”终端；
- 覆盖期权、期货、现货的算法执行云；
- 投前、投中、投后流程及 T 系列投资管理平台。

来源：[上海证券交易所《交易技术前沿》PDF，第 18 页起](https://www.sse.com.cn/services/tradingtech/transaction/c/10071290/files/cdbe5ae479af4685a853e9b4a7fdd85e.pdf)

招商证券当前官方机构下载目录还提供两类可选方案：

- **αBlade 策略工程化辅助系统**：支持现货、两融和股票期权，使用 C++/Python，提供极速行情/交易通道和策略级资金、仓位管理；页面称向“招商客户”开放框架代码和技术支持，并留有试用联系邮箱。这更接近专业量化策略框架，不是零售公开 API。[招商证券 αBlade 官方页](https://update-pb.cmschina.com/update-page/details/aboutClgc.html)
- **T-master 交易大师**：官方页面定位为机构投资者，覆盖投研、投资管理和投后分析等场景；公开页提供专用客户端但没有外部 SDK/API 规范。[招商证券 T-master 官方页](https://update-pb.cmschina.com/update-page/details/aboutJyds.html)

这证明招商证券具备机构级行情与交易接口/平台能力，但公开材料没有给出可供普通客户下载的 SDK、字段表、网络地址、价格或统一准入资产值。应将其视为招商证券主券商/PB 与机构经纪服务的一部分，而不是零售 OpenAPI。

若目标只是低频同步本人持仓，优先争取 MiniQMT/XTQuant，成本和运维明显低于极速柜台、专线、主机托管或定制接口；只有在低延迟、组合交易、独立交易单元或机构合规确有要求时，才值得进入 Geetek/X 系列的商务评估。

## 4. 监管与权限边界

程序化交易并非“拿到 API 就能直接跑”。中国证监会《证券市场程序化交易管理规定（试行）》自 2024-10-08 实施，要求程序化交易投资者报告账户、资金、交易和软件等信息，落实“先报告、后交易”。[中国证监会发布说明](https://www.csrc.gov.cn/csrc/c100028/c7480577/content.shtml)

沪深交易所的程序化交易管理实施细则自 2025-07-07 起施行，适用对象明确包括个人投资者等会员客户。客户首次进行程序化交易前，需要向接受委托的证券公司报告，由证券公司核查；高频交易、信息系统、异常交易监控另有更严格要求。[上交所现行实施细则](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20250612_10781696.shtml)、[深交所现行实施细则](https://www.szse.cn/lawrules/rule/allrules/bussiness/t20250403_612770.html)

这也是券商通常不会把交易/账户 API 做成无审核公共服务的原因之一。即便本项目目前只读行情和持仓，也应向招商证券说明用途；若以后自动下单，需要重新确认程序化交易报告、补充协议、风控和频率限制。

## 5. 招商证券国际（香港）的例外

招商证券国际公开的证券 PC/App 手册能证明客户可在官方终端查看行情和持仓，但官网同样没有发现面向普通证券客户的公开 OpenAPI。[招商证券国际桌面端操作手册](https://www.cmschina.com.hk/app-download/docs/cmshk-pc_2.0.2_user_manual.pdf)

其大宗商品业务页明确写有：可为“高频交易专业客户”提供定制化交易所直连及 API 接入，覆盖环球期货等电子交易方案。这是专业客户定制服务，不等同于港美股零售账户的公开行情/持仓 API。[招商证券国际大宗商品电子交易解决方案](https://www.cmschina.com.hk/gb/GlobalMkt/default)

如果用户实际持有的是招商证券国际账户，需要单独向其电子交易团队询问证券账户是否可接 API；不能直接套用中国内地 QMT 结论。

## 建议的最短验证路径

向招商证券客户经理或 95565 直接发送下面这组问题，避免只问“有没有 API”而被理解成公开互联网接口：

> 我的招商证券资金账号希望用 Python **只读**同步 A 股行情和本人持仓。请确认是否可申请招商证券版 QMT/MiniQMT 和 XTQuant 权限；请分别告知行情权限（L1/L2/逐笔/历史）、持仓查询权限、支持的账户类型、开通资产或交易量条件、费用、程序化交易报备要求，以及是否允许在长期运行的 Windows 主机上登录。

拿到肯定答复后，再做一个最小实机验证：启动并登录 MiniQMT，读取一只股票最新行情，调用 `query_stock_positions()`，核对证券代码、数量、可用量、成本价与招商证券官方终端一致。未完成这一步前，不应把“迅投支持招商证券”写成“当前这个账户已可用”。

## 证据强度与未确认项

- **已确认**：招商证券官方仍提供 QMT 且明确面向机构与高净值个人；XTQuant 官方 API 的行情与持仓能力；招商证券存在机构级极速行情/交易体系；现行程序化交易监管要求。
- **未公开、需账户侧确认**：招商证券 QMT 当前统一开通门槛、费用、各营业部政策、具体柜台适配、L2 权限、招商证券国际普通证券账户 API。
- **未采用**：论坛、公众号、销售博客中的资产门槛与“免门槛开户”说法，因为无法由招商证券当前官方资料交叉验证。
