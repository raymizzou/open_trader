# Dashboard 实时价格验收设计

## 目标

Dashboard 验收应证明行情能够成功拉取，且页面显示本次加载得到的有效价格。实时价格持续变化，因此不得要求页面价格等于导航前保存的旧 API 快照。

## 设计

- 保留现有 `/api/quotes` 成功、结构和价格有效性校验。
- 控制器持仓 DOM 字段继续校验，但 `last_price` 等易变字段以页面当前 `state.dashboard.broker_positions` 为基准。
- 页面 DOM 仍必须与页面状态逐字段一致，避免错误行绑定或渲染错误。
- 不冻结、不伪造行情，也不修改账户同步、持仓、行情或交易逻辑。

## 验证

- 回归测试构造导航前价格与页面当前价格不同的场景，二者不一致时仍通过。
- 同一场景下，DOM 与页面当前状态不一致时仍失败。
- 运行 `tests/test_dashboard_acceptance.py`，最终按项目门禁运行 `make acceptance`。
