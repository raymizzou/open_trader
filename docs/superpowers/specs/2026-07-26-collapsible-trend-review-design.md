# 可折叠趋势复盘设计

## 目标

趋势复盘保留在 CN、HK、US 各账户的“趋势报告”视图内，但不再默认
展开占用整页高度。它应与纪律、策略控制器和审计详情一样，作为一个
默认折叠的栏目。

## 界面

- 使用原生 `<details>`，不增加自定义状态或依赖。
- 栏目标题为“趋势复盘”。
- 摘要同时显示纪律模拟与实际执行的样本进度。
- 用户展开后看到现有完整复盘标题、截止日和指标图表。
- 独立复盘 Tab 保持删除状态。

## 数据与历史边界

- 当前趋势报告后展示当前复盘栏目。
- 趋势报告不可用时，仍可展示当前复盘栏目及其状态。
- 查看历史报告或历史报告列表时不拼接当前复盘，避免把当前数据误认为
  历史快照的一部分。
- 复盘不可用时，折叠摘要显示不可用状态，展开后显示现有状态文案。

## 验收

- 三个趋势账户仍只有“真实持仓 / 模拟盘持仓 / 趋势报告”三个 Tab。
- “趋势报告”中恰好存在一个默认关闭的趋势复盘 `<details>`。
- 展开后现有复盘指标完整可见，桌面和移动端无横向溢出。
- 历史报告中不存在当前复盘栏目。
