# 趋势交易系统复盘设计

## 状态

- 日期：2026-07-17
- 状态：已批准
- 范围：东方财富 A 股、老虎美股、辉立港股的趋势策略复盘

## 目标

为每个趋势策略市场建立独立复盘页，回答三个问题：

1. 当前执行的策略和版本是什么，完整参数是什么。
2. 纪律模拟、用户实际执行和本市场基准的表现分别如何。
3. 发生代码或查询缺陷后，能否基于冻结输入重新计算而不改写原始事实。

本期不实现参数编辑或回测入口。未来能力应为“导出参数到回测”：复制当前版本
的完整参数为可编辑回测配置，不能直接修改运行版本。

纪律模拟或实际执行未满自己的 30 笔门槛时，都不使用回测结果替代该组复盘。趋势
动物公开 API 不能按历史日期补取候选池或快照，固定当前候选池回放又会引入前视
偏差，因此页面只显示各自真实样本进度。
系统从各市场生效日起持续冻结每日候选池、行情和账户事实；未来新版本只能回测这些
已经归档的历史输入，不能补猜归档开始前或归档失败日期的数据。

## 账户内入口

复盘入口位于各券商账户头部的 `当天趋势报告` 按钮旁，不增加全局入口：

| 券商账户 | 市场 | 入口文字 | 市场基准 |
|---|---|---|---|
| 东方财富 | A 股 | `A 股复盘` | 中证全指（前复权） |
| 老虎 | 美股 | `美股复盘` | SPY（前复权） |
| 辉立 | 港股 | `港股复盘` | 恒生综合指数（前复权） |

富途账户只显示跨市场期权关注，不显示趋势复盘入口。入口按钮复用现有暖色描边按钮样式，不使用
黑色主按钮。点击后只打开该账户对应市场的复盘，A 股数据不得与港股或美股合并。

## 复盘对象与周期

每个市场独立维护一套策略版本序列、纪律模拟账户、实际执行记录和市场基准。纪律
模拟和实际执行分别统计完整持仓周期，分别达到 30 笔后解锁自己的指标。任一边达到
第 31、32 笔及以后都继续从该版本生效日累计，不分批、不重置，也不能用另一边的
样本数替代。

一笔交易指同一标的从首次买入到全部卖出的完整持仓周期。分批买入和分批卖出合并
为一笔；完全清仓后再次买入算新的一笔。纪律模拟、实际执行和市场基准使用同一版本
生效日至三方事实都完整的共同截止日，空仓等待期也必须计入。模拟或实际数据晚到时
原始事实照常保存，但最新对比投影回退到共同截止日。

当前版本的正式生效日固定为：

| 市场 | 版本 | 生效日 |
|---|---|---|
| A 股 | v1 | 2026-07-16 |
| 美股 | v1 | 2026-07-17 |
| 港股 | v1 | 2026-07-17 |

首个版本生效时，真实趋势账户已有持仓按当时标的、数量、成本和账户净值冻结为开场
事实。以后新版本只能在该市场趋势账户空仓时启用；可以先保存为候选版本并使用已归档
历史输入回测，但启用后的实盘样本必须从零重新积累。旧版本事实和指标可以追溯，不能
合并进新版本的夏普、卡玛或收益率。

## 策略身份与完整参数

复盘页顶部直接显示：

- 策略名称。
- 策略版本。
- 市场和券商账户。
- 当前运行代码实际采用的完整参数。

报告生成时冻结机器可读的 `strategy_snapshot`。它包含 `strategy_id`、
`strategy_name`、`strategy_version`、`market`、`effective_from`、生成进程的
`process_version`，以及下表列出的全部 `parameters`，不能只保存参数摘要。

Dashboard 参数表只渲染该快照，不在前端复制策略常量，也不从说明文字推断参数。
策略生成、模拟执行、复盘和未来回测导出必须消费同一个参数快照。

## 三条净值事实

### 纪律模拟

富途为港股、美股和 A 股提供独立模拟账户。每个市场模拟账户只运行本趋势实验，
因此直接使用整个模拟账户，不增加虚拟子账户。

- 从全现金、零持仓开始。
- 每个正式纪律动作在有效窗口自动提交模拟盘。
- 买入和卖出统一使用市价单；港股和 A 股从模拟盘支持的连续交易时段开始执行。
- 下单数量按模拟账户当时净值和策略目标仓位重新计算，不复制真实账户绝对股数。
- 纪律曲线直接采用富途模拟账户日终净值；不在本地重复估算或扣除费用。
- 每日冻结订单状态、持仓、现金和收盘净值。

### 实际执行

东方财富 A 股、老虎美股和辉立港股账户从各自生效日起都只用于趋势交易，因此实际
执行直接使用整个账户，不增加策略子账本。实际曲线使用真实订单、成交和每日收盘
账户净值，计入佣金、税费、利息和股息。A 股逐笔成交来自东方财富结单，美股逐笔
成交来自老虎真实账户 API，港股逐笔成交来自辉立结单。结单未上传、API 未成功或
日期不完整时，实际事实停在上一个完整日期，不从持仓差异猜测成交。

三个来源统一冻结为标的、方向、数量、成交价、费用、成交时间和来源编号。首个版本
生效日已有的真实持仓作为实际执行的未完成持仓周期；以后完全卖出时计为一笔。纪律
模拟仍从全现金、零持仓开始。

入金和出金是外部资金流，必须从收益中剔除；换汇和账户内分区转账不是新增资金。
老虎真实账户未来可通过资金明细 API 自动识别外部资金流；富途模拟账户不支持资金
流水 API，但实验账户不得发生出入金。东方财富和辉立在手工登记入口完成前不得发生
出入金；登记入口不属于本期范围。

纪律外交易保留在实际执行曲线中，因为该曲线衡量用户实际得到的结果；纪律外交易
不得进入纪律模拟样本、策略调参样本或 Kelly 样本。

### 市场基准

基准由 Futu 行情接口按日冻结前复权收盘价：A 股为中证全指 `SH.000985`，美股为
SPY `US.SPY`，港股为恒生综合指数 `HK.800701`。基准在当前版本生效日按与策略相同
的初始净值归一化，使用与两条策略曲线相同的交易日区间，不依赖人工维护的文件。

## 五项指标

主页面只展示以下五项，不增加 Alpha、Beta、胜率、盈亏比、Sortino 或综合结论：

1. **期间净收益率**：`期末净值 / 期初净值 - 1`，已扣全部费用。
2. **相对市场超额收益**：策略期间净收益率减市场基准期间净收益率；基准自身为 0。
3. **最大回撤**：每日净值相对此前峰值的最大跌幅。
4. **卡玛比率**：几何年化收益率除以最大回撤绝对值。
5. **夏普比率**：以本市场交易日日收益计算的年化超额收益均值除以年化波动率。

卡玛和夏普使用同一版本累计区间、同一交易日历和冻结的无风险收益率参数。样本不足、
最大回撤为零或收益波动为零时不生成虚假数值，明确显示数据不足。

每项计算三组值，Dashboard 再按两组配对展示：

- 纪律模拟。
- 实际执行。
- 市场基准。

## 缺陷回溯

原始报告、模拟成交、实际成交和原始净值曲线都是不可变事实。发现代码、参数映射
或 query 缺陷后：

1. 先锁定受影响的日期、报告、标的、交易和代码版本。
2. 使用当时冻结的趋势动物响应、查询参数、行情、账户和策略参数快照重放。
3. 新增纠正回放产物，记录原产物、缺陷原因、重放时间和修复 Git SHA。
4. 不覆盖原始报告、成交或原始曲线。

如果原 query 没有取得必要字段，且趋势动物不再提供对应历史日期，回放结果必须标记
为缺少历史输入，不能补猜。缺陷回放数据本期不在主复盘页展示，但冻结输入和纠正
产物必须可供审计。

## 数据产物

继续使用现有文件存储，不增加数据库：

- 每日报告证据按内容哈希保存为不可变 JSON，包含完整候选池、当时行情、账户、查询
  和响应、策略快照及生成代码版本。
- 纪律模拟事实、实际执行事实和市场基准按市场和日期分别保存为不可变 JSON，允许
  结单和 API 在不同时间到达；投影时才按共同截止日合并。
- 订单、成交和未来资金流水只追加，不覆盖原始事实；纠正通过新增回放产物表达。
- 最新指标投影和未来回测结果都是可重建的派生产物，可以原子替换，不作为第二套事实。

当前三个市场每天最多产生少量 JSON；只有多年全量参数扫描已证明文件读取成为瓶颈，
或出现多个进程并发写入时，才考虑迁移 SQLite。

## 错误处理

- 模拟账户不可用：不更新纪律模拟曲线，记录中断，不伪造成现金持有。
- 实际成交或日终净值缺失：实际执行指标显示数据不足，不使用模拟值替代。
- 基准缺失：当前版本五项对比指标不可发布，保留已有完整事实。
- 任一事实流晚到：共同截止日回退到三方最后一个连续完整日期；较新的原始事实保留，
  不删除、不覆盖。
- 归档交易日缺失：涉及该日期的未来回测标记为数据缺失，不跳过、不插值，也不用
  后一天候选池补齐。
- 新版本启用时账户仍有持仓：拒绝启用，保留为候选版本。
- 参数快照与报告动作使用的参数不一致：报告生成失败，不展示错误版本。
- 单日重复写入：按市场、账户、交易日和版本去重，保持原子写入。
- 指标计算出现非有限值：保存具体原因，不输出 `NaN` 或无穷大。

- 两条策略曲线和市场基准从当前版本生效日起使用相同日期、共同截止日和初始净值。
- 纪律模拟与实际执行各自完成 29 笔时不计算自己的指标，各自完成 30 笔时开始计算，
  第 31 笔及以后继续累计且不分批。
- 新版本只统计自己的实盘样本，旧版本不可混入；完整持仓周期只计数一次。
- 纪律模拟使用富途权威日终净值，不叠加本地费用估算。
- 东方财富和辉立结单逐笔成交、老虎真实成交 API 都映射到同一不可变事实格式；来源

- 五项指标公式、边界和数据不足状态。
- 标题右侧严格显示返回按钮、纪律模拟样本、实际执行样本和共同截止日；不得新增卡片。
