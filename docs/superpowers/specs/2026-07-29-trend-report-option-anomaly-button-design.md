# 趋势报告富途期权异动按钮设计

## 状态

- 版本：v1
- 状态：已确认
- 日期：2026-07-29
- 已选界面：A 方案，按钮放在标的名称下，不新增表格列

## 目标

把目前基于趋势字段变化生成的“期权关注”，替换为按需查看的富途期权异动：

- 仅在美股、港股趋势报告的正式买入和继续持有标的上提供入口。
- 入口读取现有 `futu_skill_facts` 的 `derivatives_anomaly`，不重新计算期权信号。
- 数据不可用时保留按钮位置并置灰，不能用趋势动物结果或推断值补齐。
- 飞书趋势报告删除整个“期权关注”段落。

## 已确认的事实边界

现有 `option_attention` 不是期权行情，而是
`market_trend.build_option_attention` 根据右侧、温度、节气、强度和风险字段变化
生成的趋势关注清单。

现有真实期权异动已经由富途事实链路生成，位于
`futu_skill_facts` 的 `derivatives_anomaly` 模块。该模块已经具备可用、缺失、
不适用、错误和过期状态，以及类别、方向、摘要、置信度和证据日期。

旧“期权关注”并没有单独调用一次趋势动物；它复用了趋势报告已有的趋势动物结果。
因此本改动不会增加趋势动物请求，也不会声称能减少趋势报告主体本来就需要的请求。
新按钮及弹窗只读取已落盘的富途事实，点击时不调用趋势动物或富途接口。

## Dashboard 交互

适用范围：

- 老虎美股当天趋势报告。
- 辉立港股当天趋势报告。
- 两份报告中的 `正式买入计划` 和 `盘中持续 · 已有持仓`。

不在卖出、人工复核、风险跳过或 A 股报告中增加入口。

每个适用标的的“标的”单元格保持现有代码与名称，其下增加
`期权异动` 按钮：

- 富途期权异动可用：蓝色按钮，可以点击。
- 缺少记录、模块缺失、权限不支持、请求错误、数据过期或日期不匹配：
  同位置灰色禁用按钮。
- 禁用状态通过 `title` 和无障碍说明保留具体原因，但不弹出空详情。
- 不新增“期权”列，桌面和移动端沿用当前趋势表格结构。

点击可用按钮后打开只读弹窗。弹窗显示：

- 标的代码和名称。
- 富途数据日期与观察窗口。
- `derivatives_anomaly` 的摘要、信号方向、置信度和建议约束。
- 全部期权异动类别及其状态、方向、详情和证据日期。

弹窗不显示技术异动或资金异动，不给出买卖建议，不提供下单入口。
现有持仓详情里的“富途异动”页签保持不变。

## 数据投影

Dashboard 服务按报告市场、报告执行日期和标准化代码读取富途事实：

```text
当前报告
  data/latest/{market}/futu_skill_facts.json

历史报告
  data/runs/{report_date}/{market}/futu_skill_facts.json
```

仅当文件内 `run_date` 与所查看趋势报告的 `report_date` 一致，且
`derivatives_anomaly.available` 为真时，按钮才可用。历史报告绝不能借用
`latest` 的当前期权异动。

服务端只向趋势行动行投影按钮所需的 `derivatives_anomaly` 视图，不把整份富途
事实复制进趋势报告，也不修改冻结的趋势报告 JSON。标的在富途事实中不存在时，
投影为明确的不可用状态。

当前富途事实任务以组合标的为输入，因此新买入计划可能没有对应记录；这种情况按
既定规则置灰。本版本不扩大富途采集范围，也不在 Dashboard 请求期间补抓数据。

## 原“期权关注”的处理

- Dashboard 删除富途账户下由 `trend_reports.futu` 投影出的
  “跨市场期权关注”入口；真实期权异动已经迁移到趋势报告行内按钮。
- 飞书趋势报告不再追加“期权关注”标题或清单。
- 已冻结历史报告和审计 JSON 不重写、不补发。
- 为兼容历史校验与回放，现有 `option_attention` 审计字段和生成逻辑暂不删除；
  它不再进入 Dashboard 或飞书操作界面。

## 失败与安全

- 所有不确定状态均失败关闭：按钮置灰。
- 不把当前富途事实展示到历史趋势报告。
- 不因富途事实缺失而阻止趋势报告主体展示。
- 不从趋势动物字段推断“有期权”或“期权异动”。
- 不在浏览器点击时触发外部请求。
- 展示层不修改报告、持仓、保护线或交易执行状态。
- 所有文本继续经过现有 HTML 转义。

## 验收

自动化与真实流程至少覆盖：

- 美股、港股正式买入和继续持有行显示行内按钮，且没有新增表格列。
- 可用富途 `derivatives_anomaly` 打开只包含期权异动的弹窗。
- 缺失、不适用、错误、过期和日期不匹配均显示禁用按钮。
- 历史报告只读取同一报告日期的富途事实；无对应归档时置灰。
- 卖出、人工复核、风险跳过和 A 股报告不出现按钮。
- 飞书有动作、无动作报告均不包含“期权关注”。
- 富途账户不再显示旧的“跨市场期权关注”入口。
- 桌面与移动端保持现有表格结构，无新增横向溢出。
- 富途事实中的恶意或异常文本不能注入 HTML。
- 最终 `make acceptance` 返回 `PASS` 后，才能交付评审。

## 非目标

- 新增期权行情、期权链、希腊字母或隐含波动率采集。
- 扩大富途事实任务的标的范围。
- 点击按钮时现场请求富途或趋势动物。
- 修改趋势动物的核心趋势报告请求、筛选或交易规则。
- 自动生成期权交易建议或执行期权订单。
- 重写或删除历史报告中的 `option_attention` 审计数据。
