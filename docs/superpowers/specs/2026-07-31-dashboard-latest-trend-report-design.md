# Dashboard 最新趋势报告设计

## 目标

Dashboard 的趋势报告主视图始终展示对应市场和券商的最新有效报告。
旧报告只通过历史报告入口查看。

## 报告选择

沿用现有报告校验，忽略无法读取、结构无效、市场不匹配或券商不匹配的
artifact。在剩余有效报告中，按以下顺序选择最新一份：

1. 数据新鲜日期；
2. 生成时间；
3. 执行日期；
4. artifact 文件名，作为稳定的最终排序键。

不再用 Dashboard 当前市场日期排除下一交易日的有效报告。报告一旦生成并
通过校验，即可进入主视图，包括上海时间已进入下一天而美股当地仍是前一天
的情况。

## 历史报告

历史接口继续返回全部有效 artifact，保持现有按执行日期、生成时间和 revision
倒序的行为。主视图选择不删除、不改写历史文件，也不改变历史报告入口。

## 失败处理

如果最新 artifact 无效，Dashboard 跳过它并展示下一份有效报告。若没有任何
有效报告，继续显示现有的“暂时不可用”状态。

## UI

不改布局、文案或交互。修复后，美股趋势报告主视图将直接展示最新 artifact
中冻结的行业上下文；旧 artifact 仍可从历史入口打开。

## 验证

- 将“跳过未来报告”测试改为“下一交易日有效报告立即成为主视图”。
- 保留“无效最新 artifact 回退到下一份有效报告”的测试。
- 增加美股跨时区回归：上海日期进入下一天、美股当地仍是前一天时，主视图
  选择最新有效报告。
- 确认历史接口仍包含新旧报告。
- 最终运行 `make acceptance`；PASS 后部署准确 accepted SHA，并核对 PID、
  工作目录、Git SHA、日志、HTTP 200 和 Dashboard 截图。
