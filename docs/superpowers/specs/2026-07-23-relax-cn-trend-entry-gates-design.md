# A 股趋势入场门槛放宽设计

## 目标

放宽 A 股趋势候选的行业温度要求，并删除没有趋势含义的静态股价上限：

- 行业温度由“热或沸”改为“温、热或沸”。
- `priceIndex <= 200` 不再是入场硬门槛。

个股仍必须由“温”转为“热”或“沸”。本次不改变仓位、风险预算、保护线或退出规则。

## 方案选择

采用最小规则调整：

1. 只放宽行业温度并保留 200 元上限，会继续按名义股价排除候选；系统已有按账户资金、实际价格和 A 股整手数计算的动态可买校验，因此不采用。
2. 放宽行业温度并删除 200 元上限，同时保留其余风险与数据要求；这是采用的方案。
3. 同时删除 ATR14，会使初始保护线、单笔风险和买入数量失去计算基准，需要另行设计止损模型，因此不纳入本次变更。

## 入场规则

A 股候选通过行业温度门槛的条件改为：

```text
industry_temperature ∈ {温, 热, 沸}
```

行业温度缺失、为“凉”或“平”时仍排除。个股温度条件保持“温→热/沸”。

`priceIndex` 继续从趋势动物读取并在报告中作为参考事实展示，但以下情况不再排除候选：

- `priceIndex` 缺失；
- `priceIndex > 200`。

能否形成买入动作继续由现有动态约束决定：账户净值、可用现金、Futu 执行参考价、100 股整手、目标仓位、单笔风险和组合风险。

## 保持不变

- 数据日期必须与纪律批次一致，防止旧信号进入新批次。
- 当前持仓不得重复开仓。
- 右侧天数必须存在，因为确定性排序仍使用“右侧天数升序”。
- ATR14 必须可计算，因为它仍用于 `成交价 - 2 × ATR14` 初始保护线、单笔计划止损风险和风险仓位计算。
- 趋势右侧、可交易、无危险信号、强度、节气、市值、成交额和证券范围要求不变。
- 美股和港股规则不变。

## 策略快照与历史兼容

这次入场口径变化生成 A 股策略 `v5`，从 `2026-07-24` 起生效，并继承
`v4` 的风险、Kelly、回撤、保护线和退出规则。美股和港股继续使用 `v4`。
新版本参数：

- `allowed_industry_temperatures` 为 `["温", "热", "沸"]`；
- 不再声明 `max_filter_price`；
- 参数表不再显示“筛选价格不高于 200 元”。

新旧版本必须隔离 Kelly 样本。已经冻结的历史报告保持不可变，并继续按各自快照解释旧原因：

- 历史 `filter_price_missing` 和 `filter_price_above_200` 仍可展示；
- 历史 `allowed_industry_temperatures` 仍显示当时的“热、沸”；
- 历史报告不得被新规则重新判定。

## 展示

当前策略说明、纪律文档和候选审计要求同步为：

- 行业温度：温、热或沸；
- 删除筛选价上限；
- 其他要求仍为数据日期一致、非当前持仓、右侧天数存在、ATR14 可计算。

候选表可继续显示“筛选价（Trend Animals）”，但它只是来源事实，不再表示通过或排除条件。

## 验证

最小自动化检查覆盖：

- 行业温度“温”“热”“沸”均通过，“凉”“平”和缺失均排除；
- 筛选价缺失或高于 200 元不再产生价格排除原因；
- ATR14 缺失仍排除；
- 当前策略快照和策略说明反映新规则；
- 旧冻结报告仍按旧快照正常加载并解释旧原因；
- 美股、港股快照和筛选结果不变。

实现完成后运行相关单元与前端测试，直接生成并检查一次真实 A 股趋势批次。最后运行一次 `make acceptance`；只有 `PASS` 后才部署同一 Git SHA 并提供复核地址。

## 非目标

- 不替换 ATR14 止损模型。
- 不改变候选排序。
- 不改变仓位上限、目标仓位、Kelly、风险预算或退出规则。
- 不新增配置项、依赖或抽象层。
