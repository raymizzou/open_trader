# 趋势报告与持仓信息分离设计

## 目标

趋势报告只展示策略报告本身，不混入账户持仓或执行状态。

## 保留内容

- 各市场趋势报告的主表与策略结论。
- 主表中的目标仓位、目标金额、预计数量和保护线；这些字段属于报告生成时的策略输出。
- “组合计划风险”和“策略累计回撤”摘要，包括 Kelly 与交易统计。

## 删除内容

- 候选主行下方的“允许/跳过、建议数量、计划止损风险、正常成本、决定性约束、原因”附加行。
- 候选主行下方的“待执行、已提交、部分成交、全部成交”等执行状态附加行。
- 组合风险摘要中嵌入的富途模拟盘执行/持仓状态。
- 组合风险摘要中嵌入的实盘持仓偏差。

不新增替代持仓页面，不修改报告 API、持仓 API 或后端数据结构。

## 实现

在现有 Dashboard 渲染层停止拼接上述附加行和持仓区块，并删除因此失去调用方的专用渲染函数。风险摘要继续直接渲染报告提供的计划风险、回撤、Kelly 和交易统计数据。

## 验证

- 先增加聚焦的 Dashboard 渲染回归断言，证明当前 HTML 仍包含待删除内容。
- 实现后确认中国、香港、美国市场报告均不再包含持仓/执行区块和候选附加行。
- 确认主报告表、组合计划风险和策略累计回撤仍存在。
- 最后运行项目完整测试和 `make acceptance`；只有 `PASS` 后才按验收 Git SHA 重启并提供 review URL。
