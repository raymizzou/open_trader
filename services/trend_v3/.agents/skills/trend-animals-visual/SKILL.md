# 趋势动物视觉下钻

默认在小程序现场用屏幕画面、点击和滚动完成。Ray 提供截图时可据图复核，结果注明“截图复核”，单列仍需现场核对的环节。单次交互请求只覆盖本次范围。定时或批量采集先读本机 `~/.codex/sops/open-trader-trend-collection/SOP.md`，核实服务方允许的方式、范围和频率；这项技能本身不启动调度或交易。

## 入口与席位

新版正式日报与手工筛选使用相同的 ≥80 做多／≤20 做空规则，保留边界与零分、全部入选大类。先读截至时间内的完整金融资产组，保存独立母榜（数据日、版次、组尾、每行名称与分数）；全国房产等其他组不混入。不得从信号榜反推母榜。旧报告只有明确 `legacy-two-seat` 或未声明版本时按历史头尾各两席读回，不以新版规则改写原件。

## 方向信号榜交叉验证（正式日报默认）

1. 逐入选类列出有独立证据的适用市场、品种组合；大类与市场可多对多，名称相似或一个符号不能证明归属。缺映射记待核。
2. 只为有入选大类的方向搜索一次完整关键字：多为「温转热」，空为「凉转寒」。从搜索结果选择准确适用组合，不假定每个市场都有两种榜。记录完整搜索结果和未覆盖组合。已核实的常用榜可复用身份，进入时仍核对标题、数据日、版次、适用市场。实际存在性和直达路径必须现场核实，离线设计不算现场验证。
3. 每张同版信号榜读到组尾一次；共享榜复用。逐行核对平台身份、市场、品种、完整标签、数据日和「移出本榜」。当前温度为冻仍可带凉转寒；从另一张节气榜移出不能取消本信号榜的在榜事实。只排除已从当前这张榜移出的成员。
4. 复用截至时间内独立核实的直属清单或直属路径，与方向信号成员按平台身份、代码、市场、品种和适用日取交集。归属证明必须独立于信号名单；缺口按同类合并查询，优先一次核实多个归属。同码异品种分开，跨类有独立归属则逐类保留，同类多来源合为一张卡。
5. 部分覆盖保留已证明命中和待核缺口；只有归属与适用信号范围双方查全且交集为空才写「无命中」。大类分数、归属、在榜和自身标签齐全可确认该卡信号；严格前后温、开仓资格和观察仓标记另核，不从标签推定。其余在报标的的行情、双强度、覆盖和负面证据要求保持。
6. 记录关键字实际搜索次数、不同榜实际读取次数、额外归属查询、总耗时、已核实命中及未覆盖数。同版同范围另以手工交集校对。离线仅报设计次数，不报实际节省百分比；比较旧路径耗时时同时写覆盖差异。纯视觉不发 API，其他入口仍按既有费用与 UNKNOWN 不重发规则执行。

点名榜单直接进入指定榜，注明来源。下文关联榜强弱排序仅用于明确点名或研究，不阻塞正式交叉验证；旧双席兼容输入保留原席位与缺项。固定证据离线复验只读指定输入，不打开微信或调用 API。

## 从页面选榜

1. 在 Mac 用 Computer Use 选官方微信应用。若同名应用有多个，使用 `/Applications/WeChat.app`，核对实际窗口标题「趋势动物Pro」。本节现场视觉证据只从该窗口的可见画面读取；官方 API 证据按下节独立取得并标明来源，不能冒充页面观察。点击前定位当前画面上的文字，翻页后核对标题、面包屑、列名和更新时间。出现安全登录提示时暂停，由 Ray 登录后重新核对起始页。窗口或路径不明时保留断点。禁止读取内部缓存、解析应用存储或拦截通信。
2. 研究入口按请求范围：在「大类资产 → 金融资产」组读「强度／页面内排名」。做多纳入 ≥80，做空纳入 ≤20，含边界和零分。按请求范围处理；核对全部时要覆盖整个金融资产组，区分同页的全国房产等其他分组。记录页面更新时间；行内数据日单独记录。
3. 进入入选大类，展开「关联品种」。在可展开的关联榜中按页面内强度选择，多头取最高，空头取最低。返回「大类资产」的入口、行业品种行和父类不参与选榜。不同层级的分数各自读取；第二层不再套用 80／20。缺分记“待核”，零是有效数值；若缺项、同分顺序或未读页可能改变首选，就报告“选榜待核”。并列且页面明确给出先后时沿用同版页面次序。需要时点击强度表头，核对排序方向和数值，不能用首行位置或旧截图代替当前分数。若 Ray 已点名某榜，仍可进入，明确注明“点名进入”。
4. 进入所选榜后核对榜名、更新时间和显示行数。滚动时留出上一屏的重叠行，直到核对组尾；同一行只计一次。逐行对应代码、名称、温度、强度列的比较范围、完整标签，以及“新增／移出本榜”等状态。若标记跨行位置不清，回滚使代码、标签和状态同时可见。只见部分行时指出覆盖范围；页头行数可能包含已移出行。
5. 做空匹配完整标签「凉转寒」，做多匹配「温转热」。当前温度即使已到「冻」，标签仍可命中。将带“移出本榜”的行单列，排除出当前在榜名单。根据可核实的市场、品种和方向另列交易资格；标签本身只作为观察结果。指定榜的查询在该榜结束。研究入口仅在明确授权的范围内顺延；正式交叉验证不顺延大类。自动选榜时，仅在榜内覆盖完整且已确认全部成员均不能按该方向交易时顺延；有可交易成员但没有标签则报“未触发”并停止，资格或覆盖未知则报“待核”。

## 免费 API 和付费批准

视觉优先。Ray 指明“纯视觉”或指定固定证据离线复验时，只使用该入口允许的证据。其他请求可直接调用当前官方费率确认整笔为零的查询，包括已确认免费的价目、更新状态和费用对账。对按字段计费的快照，须核实本次全部字段、基础费及行费均为零。预计可以命中缓存不能证明发送免费。已核实且适用的本地证据可直接复用。

本节仅允许官方 API，付费批准不授权其他接口、内部缓存或通信拦截，也不解除纯视觉／离线入口的来源限制。本次官方查询可能收费或费用不明时，先用免费价目或已有证据核价。仍可能收费则在普通聊天中列明目标、端点、字段、最多次数、费用估算及用途，取得 Ray 本次明确批准后方可发送；无法定价须如实说明。旧批准只覆盖当时范围。缺少批准时保留缺项，日报按时从可用证据成稿。遵守速率、运行锁与共享账本，结果或扣费未明时不自动重发。

分别记录页面与 API 的来源、更新时间、数据日和比较范围。同版 API 与页面成员不一致时按 Ray 指定的 API 成员口径，并列出页面所见与移出状态。API 全局或同品种强度不能填作缺失的页面内排名。

## 交付与实测参照

先交接独立母榜、适用组合、方向搜索范围、唯一榜身份／版次、逐行标签及本榜移出状态、独立直属来源和逐类手工交集。区分已核实、待核、完整无命中；数据日、报告截至时间和实际观察时间分开，晚间观察不能回填早报。

视觉结果只放现有「可做空的大类／可做多的大类」及展开区。新版保留全部入选类，旧版按旧契约读回；原直属卡仍可展示，仅给交集卡添加榜名、标签及数据日。不得新增 section、CSS 或导航；不得把搜索结果、直属证明或观察资格互相替代。未现场读过的新榜及直达路径明确待核。
