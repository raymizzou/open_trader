# 趋势动物视觉下钻

默认在小程序现场用屏幕画面、点击和滚动完成。Ray 提供截图时可据图复核，结果注明“截图复核”，单列仍需现场核对的环节。单次交互请求只覆盖本次范围。定时或批量采集先读本机 `~/.codex/sops/open-trader-trend-collection/SOP.md`，核实服务方允许的方式、范围和频率；这项技能本身不启动调度或交易。

## 从页面选榜

1. 在 Mac 用 Computer Use 选官方微信应用。若同名应用有多个，使用 `/Applications/WeChat.app`，核对实际窗口标题「趋势动物Pro」。行情数据只从该窗口的可见画面读取。点击前定位当前画面上的文字，翻页后核对标题、面包屑、列名和更新时间。出现安全登录提示时暂停，由 Ray 登录后重新核对起始页。窗口或路径不明时保留断点。禁止读取内部缓存、解析应用存储或拦截通信。
2. 在「大类资产 → 金融资产」组读「强度／页面内排名」。做多纳入 ≥80，做空纳入 ≤20，含边界和零分。按请求范围处理；核对全部时要覆盖整个金融资产组，区分同页的全国房产等其他分组。记录页面更新时间；行内数据日单独记录。
3. 进入入选大类，展开「关联品种」。在可展开的关联榜中按页面内强度选择，多头取最高，空头取最低。返回「大类资产」的入口、行业品种行和父类不参与选榜。不同层级的分数各自读取；第二层不再套用 80／20。缺分记“待核”，零是有效数值；若缺项、同分顺序或未读页可能改变首选，就报告“选榜待核”。并列且页面明确给出先后时沿用同版页面次序。需要时点击强度表头，核对排序方向和数值，不能用首行位置或旧截图代替当前分数。若 Ray 已点名某榜，仍可进入，明确注明“点名进入”。
4. 进入所选榜后核对榜名、更新时间和显示行数。滚动时留出上一屏的重叠行，直到核对组尾；同一行只计一次。逐行对应代码、名称、温度、强度列的比较范围、完整标签，以及“新增／移出本榜”等状态。若标记跨行位置不清，回滚使代码、标签和状态同时可见。只见部分行时指出覆盖范围；页头行数可能包含已移出行。
5. 做空匹配完整标签「凉转寒」，做多匹配「温转热」。当前温度即使已到「冻」，标签仍可命中。将带“移出本榜”的行单列，排除出当前在榜名单。根据可核实的市场、品种和方向另列交易资格；标签本身只作为观察结果。指定榜的查询在该榜结束。自动选榜时，仅在榜内覆盖完整且已确认全部成员均不能按该方向交易时顺延；有可交易成员但没有标签则报“未触发”并停止，资格或覆盖未知则报“待核”。

## 免费 API 和付费批准

视觉优先。Ray 指明“纯视觉”或指定固定证据离线复验时，只使用该入口允许的证据。其他请求可直接调用当前官方费率确认整笔为零的查询，包括已确认免费的价目、更新状态和费用对账。对按字段计费的快照，须核实本次全部字段、基础费及行费均为零。预计可以命中缓存不能证明发送免费。已核实且适用的本地证据可直接复用。

本次查询可能收费或费用不明时，先用免费价目或已有证据核价。仍可能收费则在普通聊天中列明目标、端点、字段、最多次数、费用估算及用途，取得 Ray 本次明确批准后方可发送；无法定价须如实说明。旧批准只覆盖当时范围。缺少批准时保留缺项，日报按时从可用证据成稿。遵守速率、运行锁与共享账本，结果或扣费未明时不自动重发。

分别记录页面与 API 的来源、更新时间、数据日和比较范围。同版 API 与页面成员不一致时按 Ray 指定的 API 成员口径，并列出页面所见与移出状态。API 全局或同品种强度不能填作缺失的页面内排名。
